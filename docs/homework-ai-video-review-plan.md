# Homework AI Video Review Plan

## Purpose

The Playwright QA tests check DOM logic, button wiring, answer correctness, clip timing ranges, and network/console errors. They cannot truly judge whether the displayed text is visually correct to a child, and they cannot listen like a human.

This AI video review flow records the game screen as MP4 so a vision-capable AI or human reviewer can inspect the visual state and text labels.

## What This Review Should Check

Use a distrust-everything approach.

### Visual Text / OCR Checks

The reviewer should verify that the video clearly shows:

```text
- YURI Brighter Phonics Train title
- Level 2 / Brighter Phonics Train entry
- A/E/I/O/U station route
- Sound Ticket Board
- Review row selector changes correctly
- AB / AM / AZ are visible for A Station
- EB / EM / EZ are visible for E Station
- IB / IM / IZ are visible for I Station
- OB / OM / OZ are visible for O Station
- UB / UM / UZ are visible for U Station
- audioStatus text changes after each ticket tap
- Quiz screen shows 4 answer tickets
- The correct answer ticket exists after audio is played
- Wrong answer shows retry feedback
- Correct answer shows success feedback
- Result screen shows final score and arrival message
```

### Button / Logic Checks

The reviewer should verify:

```text
- Level 2 button enters the game
- Review station dropdown changes station
- First / middle / last ticket per station can be tapped
- Audio status updates after tapping a ticket
- Quiz starts correctly
- Listen button changes audio status
- Wrong answer does not increase score
- Correct answer increases score
- Next Station advances the quiz
- Result screen appears after 5 questions
- Restart and Home flows work
```

### Audio Review Limitation

The MP4 generated by Playwright may not contain reliable real browser audio in headless mode. The video review is mainly for visual recognition and UI logic.

For real audio correctness, manually listen to these 15 clips on iPhone Safari or desktop browser:

```text
A: AB / AM / AZ
E: EB / EM / EZ
I: IB / IM / IZ
O: OB / OM / OZ
U: UB / UM / UZ
```

Each clip should play the final blend only, not the full teaching sequence.

## Codex Command

From repo root:

```bash
npm install
npx playwright install chromium

HOMEWORK_URL="https://hkspurs.github.io/yurilearning/phonics-game/homework.html?v=gggeeeggu" \
node tests/homework-record-ai-review.js
```

The script should generate:

```text
test-results/homework-ai-review/homework-ai-review.webm
```

If MP4 conversion is available through ffmpeg, Codex can run:

```bash
ffmpeg -y -i test-results/homework-ai-review/homework-ai-review.webm \
  -c:v libx264 -pix_fmt yuv420p \
  test-results/homework-ai-review/homework-ai-review.mp4
```

## Prompt for AI Video Review

Use this prompt when uploading the video to an AI vision model:

```text
Please review this recorded Playwright video of a children's phonics web game.

Use a skeptical QA mindset. Check the visible text, buttons, station route, answer tickets, feedback messages, and result screen.

Confirm whether the following are visually correct:
1. The title is YURI Brighter Phonics Train.
2. The Level 2 / Brighter Phonics Train game opens.
3. The A/E/I/O/U station route appears.
4. The review screen shows Sound Ticket Board.
5. For each station, first/middle/last tickets appear:
   A: AB / AM / AZ
   E: EB / EM / EZ
   I: IB / IM / IZ
   O: OB / OM / OZ
   U: UB / UM / UZ
6. After tapping a ticket, audioStatus shows the same label.
7. Quiz screen shows 4 answer tickets.
8. Wrong answer gives retry feedback.
9. Correct answer gives success feedback and score increases.
10. Result screen appears after the quiz.

Report:
- PASS/FAIL
- Any text mismatch
- Any button/layout problem
- Any confusing screen
- Any issue that needs human follow-up
```

## QA Decision Rule

```text
Playwright full QA PASS + AI video review PASS + manual 15-clip audio spot check PASS = ready for parent/child playtest.
```
